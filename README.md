# Job Board Frontend

React frontend za Job Board aplikaciju.

## Tech Stack
- React + Vite
- React Router
- Axios

## Pokretanje
```bash
npm install
npm run dev
```

Otvori http://localhost:5173

## Funkcionalnosti
- Lista oglasa sa pretragom po tech stacku
- Registracija i login
- Dodavanje oglasa (za ulogovane korisnike)
- Povezano sa Job Board API backendom
